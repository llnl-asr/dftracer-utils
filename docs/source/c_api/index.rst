C API Reference
===============

The stable C ABI: a flat C interface to the engine for C consumers,
foreign-function bindings, and hand-written plugins. The C++ types are the
reference implementation; the ABI is the boundary that stays stable across
versions. Each page documents one header group from the source through Doxygen.
