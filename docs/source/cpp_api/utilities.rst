Utilities
=========

Generic building blocks under ``dftracer::utils::utilities`` and its siblings:
file I/O and compression, the line sources, parallel helpers, the filesystem and
hashing utilities, DLIO config generation, replay, trace generation, statistics
(DDSketch, histograms), serialization, and the JSON layer.
